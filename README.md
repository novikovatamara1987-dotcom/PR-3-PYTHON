1. Для чего используются циклы в языке программирования?
Цикл — это конструкция, многократно выполняющая одну и ту же группу операторов.
Число повторений (итераций) может быть задано заранее или зависеть от истинности
некоторого условия. Циклы применяются для перебора значений, накопления сумм и
произведений, обработки последовательностей данных, поиска и т. п., что избавляет
от многократного дублирования кода.

2. Какие виды циклов реализованы в языке Python?
Два вида:
1) цикл с предусловием — while;
2) цикл с параметром — for (перебор элементов итерируемого объекта, часто с
   функцией range()).

3. Каков синтаксис оператора цикла while?
while <условие>:
    <оператор1>
else:
    <оператор2>
Сначала проверяется условие; пока оно истинно, выполняется тело цикла (с отступом).
Если условие ложно сразу, тело не выполнится ни разу. Блок else необязателен и
выполняется, если цикл завершился без break. Внутри тела нужно менять переменные
условия, иначе цикл станет бесконечным.

4. Каков синтаксис оператора цикла for?
for <переменная> in <объект>:
    <оператор1>
else:
    <оператор2>
Цикл перебирает элементы итерируемого объекта (строка, список, range и др.), на
каждой итерации присваивая очередной элемент переменной цикла. Для числовых
последовательностей используется range(finish), range(start, finish) и
range(start, finish, step); finish в последовательность не входит. Блок else
выполняется, если выход произошёл не по break.

5. Для чего используется оператор break внутри тела цикла?
Оператор break немедленно прерывает выполнение цикла (досрочный выход), после чего
управление передаётся оператору, следующему за циклом. При выходе по break блок
else цикла не выполняется. Во вложенных циклах break завершает только тот цикл, в
котором он записан.
